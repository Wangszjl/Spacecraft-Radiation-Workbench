# 基础建模与三维结果联动：0.1.1 本地验收

日期：2026-10-30。本批已完成独立桌面应用与可嵌入工作台共用的基础建模流程；首批架构和 0.1.0 的历史证据见 [BOOTSTRAP_ACCEPTANCE.md](BOOTSTRAP_ACCEPTANCE.md)。

## 使用入口

本机打开 [SpaceRad 0.1.1](../dist/SpaceRad-0.1.1-local/spacerad.exe)。包内 `runtime.json` 已指向本机固定 Geant4 11.4.3 数据目录；数据未打包，跨机器安装验收仍待完成。旧 0.1.0 目录保留。

1. 选择“新建基础工程”或“简化整星示例”。基础工程是可计算的最小示例，不是空白模型。
2. 在“模型属性”中选择“添加部件 / 敏感区”，填写稳定 ID、形状、材料、敏感标记、父装配、位置、尺寸与旋转。圆柱沿局部 Z 轴；球体尺寸表示直径；箱体可设置壳壁厚。
3. 通过模型树或属性表选择部件，再编辑或删除。重名、重叠、越出源球及删除最后一个敏感区等不合法操作会被拒绝；对话框中的错误不会提交半份工程。
4. 另存并重开工程，设置谱和历史数，运行 Geant4。选择剂量表中的敏感区，会同步到模型树、属性表与三维高亮，并调整相机。隐藏部件可临时显示定位；存储的可见性及输运计分不变。
5. 结果仍可导出 CSV/JSON。改动工程参数会清除旧的接受结果，单纯选择与定位不会清除结果。

当前 TKMaster 的“仿真 → SpaceRad 辐射分析组件...”使用同一个工作台，并已重新构建。公开 `Authoring.h` 提供不修改原始工程的建模操作，公开选择 API 方便宿主同步列表，详见 [EMBEDDING.md](EMBEDDING.md)。

## 结果解释与仍待工作

新增硅敏感区为 20×20×1 mm，质量约 0.000932 kg，保持 `visible=false` 时仍出现在五靶计分结果中。10,000 历史的交互测试中该小目标零命中，RSE 为未知；这只证明流程和目标纳入计分，不能解释为零风险或剂量精度达标。其余靶区也必须结合统计误差解释。

本批沿用已有合成谱和用户 CSV 输入，没有执行 AP8/AE8、AE9/AP9 或真实轨道环境模型；材料名在 Worker 中解析，界面不提供材料认证。模板派生部件可定位，本轮对话框只编辑显式编写的部件。任意 CAD 编辑、器件 DDD/SEE、独立物理基准、干净机器安装、CI 与 GitHub 公开发布条件仍在[后续清单](RELEASE_READINESS.md)中。
