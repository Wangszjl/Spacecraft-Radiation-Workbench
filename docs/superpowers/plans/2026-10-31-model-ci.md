# Independent model builds and continuous integration

- [ ] 1. Make a Qt/VTK/Geant4-free model-only CMake configuration, with explicit dependency guards and component-aware installed package metadata.
- [ ] 2. Build and test the model on this workstation; install to a path with spaces, relocate the SDK, and build/run an independent consumer with dependency discovery disabled.
- [ ] 3. Add Windows/MSVC and Linux/GCC model CI, run it on GitHub, inspect actual results and fix failures.
- [ ] 4. Rebuild/check the current full desktop configuration, document supported scope and push the completed changes and evidence links.

This milestone validates source/build/install portability for the model library. A successful model CI does not establish Linux desktop, Geant4 transport or clean-machine runtime acceptance. CI logs may be uploaded; no bundled SDKs, Geant4 datasets or desktop runtime are published by this workflow.
