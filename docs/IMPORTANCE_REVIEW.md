# 加权输运统计明细

工作台现在可以直接查看每个敏感区的来源区域支持程度，并在当前结果和历史任务中显示同一套统计筛查。输入为经过服务或档案核对的 schema-v8 整目标输运结果；不重新运行物理输运。

## 桌面流程

1. 对 v8 工程完成一次真实运行后，点击“加权输运统计明细”。当前项目修改会清除已接受结果并禁用该按钮。
2. 或在“历史任务 / 剂量对比”载入 A／B 加权任务，点击“A 加权统计明细”或“B 加权统计明细”。未载入、加载失败或普通未加权任务对应按钮禁用。
3. 上表列出全部敏感区的 TID、经验 SE/RSE、MC 筛查状态、低命中区域和零命中区域；选择靶区后，下表显示每个粒子的主体／尾部能段、抽样历史数、非零沉积历史数和物理剂量贡献。
4. 导出完整统计 JSON 或全部靶区的来源分组 CSV。界面使用易读有效数字，提示和导出保留完整精度。导出反馈不会清除统计限制说明。

窗口使用打开时的独立快照，查看与导出不会改变宿主工程、当前计算结果或发出新的分析信号。项目变化、历史侧清除或重新选择失败后，已经打开的快照仍可阅读。关闭历史窗口会同时关闭其子明细窗口。

固定桌面筛查策略为每个粒子／能量区域至少 20 次非零沉积、靶区经验 RSE ≤20%。即使 RSE 已小于20%，只要有低／零命中来源区域，仍显示“统计不足”。“通过 MC 筛查”仅表示满足这一经验门槛，不是外部物理验证、置信覆盖保证或工程验收。

## 计分重建与协方差

令总历史数为 N，一个区域实际抽样数为 k，条件带权沉积均值为 μ、M2 为该区域的离差平方和。区域对全事件均值的贡献为 kμ/N；其含全部其他零事件的 M2 为 M2+kμ²−N(kμ/N)²。以原谱总预期入射数和目标质量换算区域剂量及单独贡献的经验标准误。

不同区域共用同一批总历史，且一次事件仅属于一个粒子／能量区域。因此区域贡献并非独立估计，不能把区域 SE 平方直接相加作为总剂量方差。API 保留整区原始标准误，并报告各区域独立列出的方差和与交叉协方差项；两者相加重建整区观测方差。

## 公共 API 和 CLI

模型 API 不依赖 Qt、VTK 或 Geant4。链接 `SpaceRad::Model`：

~~~cpp
#include <spacerad/ImportanceReview.h>
auto review = spacerad::importanceReview(project, acceptedResult);
~~~

默认阈值与桌面相同。API 可显式传入最少非零历史数和最大总 RSE，输出记录实际策略。它复验加权源配置、区域计分矩和剂量，核对完成状态、物理工程及敏感区集合；不修改输入。普通未加权工程返回 `not_applicable`。

加权 `spacerad_cli run` 的完成事件和 `inspect-result` 的档案摘要都包含 `importance_review`，与 GUI／导出使用同一实现。原始 Worker `result.json` 继续保存原始矩；审查是可重复生成的派生结果。
