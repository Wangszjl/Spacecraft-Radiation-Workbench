## 算例和检查含义

靶区为直径20 mm的硅球，源球半径11 mm，使用显式合成电子／质子微分谱。选择这种几何是为了让靶区得到充分命中，并能与解析几何和源抽样关系对照。

| flux算例指标 | 本次两端观测 |
|---|---|
| 敏感区质量 | 0.00975988117715229 kg |
| 初级粒子入靶历史 | 8230 / 10,000 |
| 非零沉积历史 | 8230 / 10,000 |
| TID估计 | 1.3157550977499842e-6 Gy |
| MC相对标准误差 | 约0.7374% |

检查覆盖以下关系：同一运行环境中固定seed重复的剂量与原始矩一致；flux与按64秒换算后的fluence一致；暴露从64秒改为128秒时剂量加倍、输运原始矩与RSE不变；质量符合球体体积与硅密度；剂量和标准误差可由事件矩重建。入靶概率参考 `(10/11)^2`，入射余弦均值参考 `2/3`，两项均通过预先设定的六倍标准差界限；双粒子抽样份额也符合谱积分比例。

这次两端的剂量与命中数一致，RSE末位存在浮点尾差；自动验收仅要求各环境内部的seed一致性，不把跨平台逐位相等作为通用保证。服务检查还包含独立的短任务和百万历史任务的忙时／取消／篡改测试。

## 使用与边界

[构建和运行指南](WORKER_BUILD.md)给出独立Worker的编译命令和可复用验收脚本。它在新目录保留每次输入、结果和日志，拒绝覆盖既有目录。数据别名只允许相同版本且限定的`G4`前缀差异；不会把任意非空数据目录冒充成指定版本。Worker仍会审计清单SHA、构建上下文及自身身份。

这些是软件、源抽样和解析几何检查，不是实验剂量基准或航天器任务认证。尚未执行真实轨道环境模型、独立剂量物理验证或器件DDD/SEE。Linux桌面渲染、Windows托管Worker CI、干净机器桌面安装、许可证和正式二进制发布仍在[后续清单](RELEASE_READINESS.md)中。
