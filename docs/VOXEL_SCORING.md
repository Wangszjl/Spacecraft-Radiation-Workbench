# SpaceRad 0.1.6：空间剂量体素计分

体素计分将一个均匀、实心、敏感盒实体细分成同材料的等质量格，在输运时逐格累计 TID 能量沉积、事件矩、非零历史和每靶单事件沉积能谱。它是空间分辨剂量估计，不是自动热点认证。

## 桌面操作

1. 打开 [体素示例工程](../examples/projects/voxel-scoring.json)，或给现有整星工程添加一个均匀实心敏感盒。
2. 在“计算参数”中启用“体素 TID 计分”，选中目标盒，设置 X/Y/Z 划分数和沉积能量边界，然后点击“应用体素设置到工程”。网格每轴为 1–32，最多 4096 格；每格边宽至少 `1e-4 mm`。仅可划分直接几何或展开模板后的敏感实心盒，禁止空心、球、圆柱和非敏感体。
3. 另存工程，运行 Geant4。Worker 逐历史对细胞打分；接受结果前，服务校验每格结果、总目标能量守恒和事件能谱。
4. 点击“查看空间剂量体素图”，选择 X/Y/Z 法向和切片号。二维面片填色代表该均匀质量格的 TID；灰色格表示零命中，不能读作零风险。三维视图叠加方向/位置正确的体素块；已有组件选择、高亮会保留。
5. 可导出 `field.json`、`field.vti`、`field.csv` 和逐文件 SHA-256 manifest。

网格属于工程本身：schema v7 中 `voxel_scoring` 记录体积 ID、三轴计数、单事件沉积能边界与质量分类阈值。启用或编辑网格会使此前计算结果失效。禁用时会删除该设置，并回到原有整体敏感区计分。

## 数据含义与限制

各格同属所选盒的材料，以精确均匀格质量归一化。TID、`rad=100 Gy`、逐格 MC 标准误差、RSE 和质量分类来自同一批完整历史。因为各格质量相同，逐格 TID 的质量加权平均（也就是算术平均）与整区 TID 一致；不能把各格 TID 直接相加。引擎会校验每源历史的各格能量矩之和与整区对应能量矩一致。沉积能谱按敏感目标和每源历史给出，包含零沉积事件及上溢格；它不是注量谱。CSV 用于分析，VTI 保留世界位置、旋转和均匀网格，可在 ParaView 等 VTK 工具中查看。

质量分类使用用户设定的最少非零历史和最大 RSE，分类状态只描述抽样精度门槛。零命中时 RSE 未知，不意味着剂量为零或风险为零。不同体素格的抽样相关性未导出；不能把各格标准误差当成互相独立后合并，也不能把最大采样格称为显著热点。细化网格会改变统计质量与方差，但不应任意指定网格以筛选期望结果。

当前只支持均匀实体盒，不模拟细胞内部材料差异、弯曲或 CAD 实体体素化，也不作空间插值。任务级谱仍按现有全向、各向同性、电子 / 质子模型定义。轨道环境执行、实验剂量基准、独立剂量物理验证、DDD / SEE 响应模型尚未实现；不可用合成示例进行任务鉴定。

## CLI 和 SDK

普通 `spacerad_cli run` 会按工程快照执行 v7 设置并将 `voxel_field` 与 `edep_spectra` 写入 `result.json`。缺字段或字段与原始矩不一致时，服务拒绝结果。真实 Worker 可从完整作业导出空间文件：

```powershell
.\scdat_radiation_worker.exe --export-voxels `
  C:\SpaceRad\voxel-job\project.json `
  C:\SpaceRad\voxel-job\result.json `
  C:\SpaceRad\new-voxel-export
```

输出目录必须为新目录；JSON、CSV、VTI 和 manifest 采用暂存后一次发布。Qt 宿主可链接 `SpaceRad::Model` 调用 `configureVoxelScoring` / `disableVoxelScoring`，或链接 `SpaceRad::Services` 调用 `exportVoxelResult`。相同 `WorkbenchWidget` 在独立桌面和宿主嵌入场景中提供配置和切片查看。

API 仅使用解析几何和固定网格边界，不依赖 VTK。VTK 只在 GUI 或后处理应用中用于呈现。
